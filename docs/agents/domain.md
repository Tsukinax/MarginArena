# Domain docs

This repo has a single context.

- **Glossary:** `CONTEXT.md` at the repo root. Skills that look for `GLOSSARY.md` should use `CONTEXT.md`, not create a new file.
- **Decisions:** ADRs in `docs/adr/`.
- **Planning map and tickets:** `.scratch/marginarena/` (see `docs/agents/issue-tracker.md`).

Read `CONTEXT.md` and the relevant ADRs before working in an area, and use the glossary's terms in code, UI copy and docs.
