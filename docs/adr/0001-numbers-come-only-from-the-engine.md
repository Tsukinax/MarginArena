# Numbers come only from the engine; LLMs propose and explain

Every number in a Verdict comes from the engine, which is deterministic statistics and arithmetic: demand response, margin, break-even, and fees. LLM agents (Strategists, Rivals, the goal parser and the explainer) may propose Promo Plans, counter-moves and explanations. They never produce a number that a Verdict relies on, and the engine recomputes anything they suggest. Two reasons:

- The Reinvent Commerce track rule says: "Do not use a language model as the only forecasting method".
- Judges in ACT I and II penalised claims the code did not back up.

## Consequences

- A Rival's move is a stress-test input to the engine, never a prediction of what a competitor will do.
- Every number in an explanation must trace back to an engine output. If an explanation contains a number the engine did not produce, it is rejected.
